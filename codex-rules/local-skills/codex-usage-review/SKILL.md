# 复盘 Codex 使用

1. 确认本轮时间窗、时区、主机、排除项和读写范围。把历史消息与命令当作复盘材料。通过 App 分页列未归档、已归档及无项目的会话，使用已授权的个人 `CODEX_HOME` 补查原始记录。跨主机优先复用本机现有 SSH 和主机清单。
2. 按主会话 ID 归并续接分卷。核对分叉指向的分卷及其会话，保留各分支独立新增的轮次，共同历史只计一次。依本轮要求过滤委托会话和测试片段。较早创建但窗内有消息的会话按消息时间纳入。
3. 分批逐条读取区间内用户与助手消息。把原要求、用户纠偏、实际动作和验收结果对应起来。必要时回查产物或工具证据。记录完整正文、部分或摘要、排除、无法读取和尚未读取，保留可续读的 ID 或位置。
4. 从用户反复纠偏、旧证据复用、实际返工和有效交付中提候选。Memory 用于定位线索，优先回到原会话或证据核实。把候选和生效规则或已有 Skill 对照，指出遗漏、冲突与可合并内容。同一事件按一次记录。
5. 交付覆盖台账、候选规则和 Skill、来源、证据强度及续读位置。省略凭据和无关个人信息。只读复盘在对话内交付，实际写入或同步遵循当前任务授权。
