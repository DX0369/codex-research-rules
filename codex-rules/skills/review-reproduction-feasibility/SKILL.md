# 判断科研复现可行性

1. 明确要复现的结论或方法，以及可用的模型、API、算力、时间和数据。先查已有调研与证据，按用户确认的实验目标评价候选。
2. 核对论文协议与官方发布的代码版本、数据和划分、权重、依赖及评测入口。检查源码或发布物中实际可运行的部分，指出会影响复现的论文与实现差异。
3. 逐项说明论文报告、可取得或已核对的发布资源、当前环境实测证据。按用户需要区分完整复现、部分验证和改动设置后的方法复现。
4. 交付对照结论、关键缺口和最值得优先核验的一步，说明什么结果会改变复现选择。方案确定后可用 `prepare-research-run` 准备命令和运行验证。
