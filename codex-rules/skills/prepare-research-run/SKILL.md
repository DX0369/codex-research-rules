# 准备科研运行

1. 确认本轮范围是准备命令、做有界验证，还是启动指定运行。正式启动遵循全局 `AGENTS.md` 的授权条款。
2. 结合用户已确认的决定、项目文档、实际代码及配置，核对入口、环境、协议、输入输出和资源门槛。评测涉及样本身份、数据划分、指标和失败处理时，核对本次实际口径。
3. 检查已有 smoke、测试、运行记录和相关产物是否覆盖本次入口与受影响环节。只补已有证据无法覆盖的部分。需要 smoke 且本轮授权允许时，使用真实链路和独立临时输出。
4. 跨实现对照时核对同名参数实际控制的对象、层级和单位。消融或禁用时核对实际执行路径。资源有疑问时查目标运行环境。需要切换且有活跃作业时，核对作业绑定的代码版本或工作树。
5. 调度作业或容器中的任务需要联网时，核对实际生效的直连、代理和镜像设置。Slurm 作业核对代理变量从 `sbatch` 提交环境到 `srun` 或实际子进程如何传递。复用同执行环境、同服务的已有证据。网络路径或运行环境变化使证据不足，或发生联网故障时，只验证受影响的请求。只需核对连通性或认证时，可在等效运行环境的短 CPU 作业中使用实际客户端验证。
6. 交付可复制命令、已有证据和未满足条件。获准启动且条件满足时，使用项目入口执行，并凭证据报告已排队、实际运行中、产物待验收或验收完成。仅核查既有运行时使用 `audit-experiment-status`。
