# 科研调研与续接

1. 明确本轮要回答的问题和会影响判断的约束。先读相关项目文档、已有调研入口和结果。查看上次查到何时、用过哪些来源、读到哪种证据，以及仍待查的问题。
2. 优先引用适用于本轮的已有证据。用户要查最新进展时，从上次覆盖时间和来源补查。问题或设置改变时，复用有关的材料，再核对影响新判断的证据。关键主张优先核对论文正文、正式发布物和官方实现。把摘要、正文、代码、项目实测和社区线索按实际证据表述。查新结论注明范围和截止时间。
3. 需要留存时，优先沿用用户指定位置，其次更新项目已有调研入口。首次留存且没有指定位置或已有入口时，在具体科研子项目根目录下建立 `research/README.md`，并在项目说明中链接该入口。同主题续查经授权留存时更新原文档。有明确独立用途的专题可在同一调研目录增加专题页，由入口链接。只读任务在对话内交付。
4. 记录当前结论、支持它的出处及适用条件、已查范围和日期、尚未解决的问题。优先使用 DOI、arXiv ID 或官方链接定位文献，结论依赖特定版本时标明版本。需要保存全文时，沿用已有论文库或在调研目录下用 `papers/` 集中保存，同一份文件由多个主题引用。关键结论可定位到页、节、表图或代码版本。
5. 交付本轮新增或修正的判断、关键证据和下一轮值得补查的问题。需要实际判断公开资产和当前资源能否复现时，接用 `review-reproduction-feasibility`。
