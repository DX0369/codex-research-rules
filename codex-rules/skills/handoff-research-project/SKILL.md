# 交接科研项目

1. 确认接手者要继续执行、恢复环境，还是审阅研究路线。读取当前项目说明、状态、实际入口、已保存配置和相关运行证据，核对活跃作业使用的版本。
2. 继续工作时，交付当前入口、环境、必需的代码和资产、来源或生成方式，以及可直接继续的下一步。移机时核对目标机上的可用路径和依赖，说明压缩包完整性、目标机可用性和复现分别验到哪一步。
3. 给评审者准备能独立读懂的文档。说明研究问题和当前方案，记录数据来源、版本、划分与处理，训练或推理设置，各对照的实际运行、评测口径、结果、失败和未完成项。用证据解释可比范围和当前判断。列出希望对方回答的问题，以及不同判断会怎样影响下一步。
4. 使用可定位的产物和小段证据。说明仅由诊断支持的观察、仍不可访问的资料和待确认事实。普通会话交接可复用已有项目文档。用户要求详细评审材料时交付一份可独立转交的正文。
